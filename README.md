## 📦安装方法
  1、在 Releases 下载最新的 .mcpb 安装包。
  2、打开 Claude Desktop → 设置 → 扩展 → 浏览插件 → 高级设置 → 安装扩展。
  3、选择下载的 .mcpb 文件，确认安装。
  4、安装完成后，添加Codex数据和缓存配置。然后确认 CCMemories for Claude 已启用。
  5、新建一个普通聊天，即可让 Claude 搜索和读取 Codex 会话。

💬例如，直接发送：
> 搜索最近的 Codex 工作会话。

> 读取“CCMemories”工作会话。

> 继续读取这条会话更早的消息。

## 主要功能
| MCP 工具 | 功能说明 |
|---|---|
| `list_work_threads` | 列出最近的 Codex 工作会话 |
| `search_work_threads` | 根据标题或关键词搜索工作会话 |
| `search_work_messages` | 搜索历史会话中的消息正文 |
| `read_work_thread` | 读取指定会话，支持分页与历史续读 |
